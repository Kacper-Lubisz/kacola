# GObject elements

Elements in this namespace are imported from `@gtkx/jsx/gobject`; the matching classes, enums, and functions are imported from `@gtkx/gi/gobject`.

| Element | Description |
| --- | --- |
| [GBinding](.gtkx/reference/gobject/binding.md) | GObject instance (or source) and another property on another GObject instance (or target). |
| [GBindingGroup](.gtkx/reference/gobject/binding-group.md) | GBindingGroup can be used to bind multiple properties from an object collectively. |
| [GInitiallyUnowned](.gtkx/reference/gobject/initially-unowned.md) | A type for objects that have an initially floating reference. |
| [GObject](.gtkx/reference/gobject/object.md) | The base object type. |
| [GSignalGroup](.gtkx/reference/gobject/signal-group.md) | GSignalGroup manages a collection of signals on a GObject. |
| [GTypeModule](.gtkx/reference/gobject/type-module.md) | GTypeModule provides a simple implementation of the GTypePlugin interface. |
