# GtkSource elements

Elements in this namespace are imported from `@gtkx/jsx/gtksource`; the matching classes, enums, and functions are imported from `@gtkx/gi/gtksource`.

| Element | Description |
| --- | --- |
| [GtkSourceAnnotation](.gtkx/reference/gtksource/annotation.md) | Represents an annotation added to View, it has a Annotation.line property, Annotation.description, icon and a style. |
| [GtkSourceAnnotationProvider](.gtkx/reference/gtksource/annotation-provider.md) | It is used to provide annotations and display them on View and also populate HoverDisplay when the user hovers over an annotation. |
| [GtkSourceAnnotations](.gtkx/reference/gtksource/annotations.md) | Use this object to manage Annotations. |
| [GtkSourceBuffer](.gtkx/reference/gtksource/buffer.md) | Subclass of Gtk.TextBuffer. |
| [GtkSourceCompletion](.gtkx/reference/gtksource/completion.md) | Main Completion Object. |
| [GtkSourceCompletionCell](.gtkx/reference/gtksource/completion-cell.md) | Widget for single cell of completion proposal. |
| [GtkSourceCompletionContext](.gtkx/reference/gtksource/completion-context.md) | The context of a completion. |
| [GtkSourceCompletionSnippets](.gtkx/reference/gtksource/completion-snippets.md) | A CompletionProvider for the completion of snippets. |
| [GtkSourceCompletionWords](.gtkx/reference/gtksource/completion-words.md) | A CompletionProvider for the completion of words. |
| [GtkSourceFile](.gtkx/reference/gtksource/file.md) | On-disk representation of a Buffer. |
| [GtkSourceFileLoader](.gtkx/reference/gtksource/file-loader.md) | Load a file into a GtkSourceBuffer. |
| [GtkSourceFileSaver](.gtkx/reference/gtksource/file-saver.md) | Save a Buffer into a file. |
| [GtkSourceGutter](.gtkx/reference/gtksource/gutter.md) | Gutter object for View. |
| [GtkSourceGutterLines](.gtkx/reference/gtksource/gutter-lines.md) | Collected information about visible lines. |
| [GtkSourceGutterRenderer](.gtkx/reference/gtksource/gutter-renderer.md) | Gutter cell renderer. |
| [GtkSourceGutterRendererPixbuf](.gtkx/reference/gtksource/gutter-renderer-pixbuf.md) | Renders a pixbuf in the gutter. |
| [GtkSourceGutterRendererText](.gtkx/reference/gtksource/gutter-renderer-text.md) | Renders text in the gutter. |
| [GtkSourceHover](.gtkx/reference/gtksource/hover.md) | Interactive tooltips. |
| [GtkSourceHoverContext](.gtkx/reference/gtksource/hover-context.md) | Context for populating HoverDisplay contents. |
| [GtkSourceHoverDisplay](.gtkx/reference/gtksource/hover-display.md) | Display for interactive tooltips. |
| [GtkSourceLanguage](.gtkx/reference/gtksource/language.md) | Represents a syntax highlighted language. |
| [GtkSourceLanguageManager](.gtkx/reference/gtksource/language-manager.md) | Provides access to Languages. |
| [GtkSourceMap](.gtkx/reference/gtksource/map.md) | Widget that displays a map for a specific View. |
| [GtkSourceMark](.gtkx/reference/gtksource/mark.md) | Mark object for Buffer. |
| [GtkSourceMarkAttributes](.gtkx/reference/gtksource/mark-attributes.md) | The source mark attributes object. |
| [GtkSourcePrintCompositor](.gtkx/reference/gtksource/print-compositor.md) | Compose a Buffer for printing. |
| [GtkSourceRegion](.gtkx/reference/gtksource/region.md) | Region utility. |
| [GtkSourceSearchContext](.gtkx/reference/gtksource/search-context.md) | Search context. |
| [GtkSourceSearchSettings](.gtkx/reference/gtksource/search-settings.md) | Search settings. |
| [GtkSourceSnippet](.gtkx/reference/gtksource/snippet.md) | Quick insertion code snippets. |
| [GtkSourceSnippetChunk](.gtkx/reference/gtksource/snippet-chunk.md) | A chunk of text within the source snippet. |
| [GtkSourceSnippetContext](.gtkx/reference/gtksource/snippet-context.md) | Context for expanding SnippetChunk. |
| [GtkSourceSnippetManager](.gtkx/reference/gtksource/snippet-manager.md) | Provides access to Snippet. |
| [GtkSourceSpaceDrawer](.gtkx/reference/gtksource/space-drawer.md) | Represent white space characters with symbols. |
| [GtkSourceStyle](.gtkx/reference/gtksource/style.md) | Represents a style. |
| [GtkSourceStyleScheme](.gtkx/reference/gtksource/style-scheme.md) | Controls the appearance of View. |
| [GtkSourceStyleSchemeChooserButton](.gtkx/reference/gtksource/style-scheme-chooser-button.md) | A button to launch a style scheme selection dialog. |
| [GtkSourceStyleSchemeChooserWidget](.gtkx/reference/gtksource/style-scheme-chooser-widget.md) | A widget for choosing style schemes. |
| [GtkSourceStyleSchemeManager](.gtkx/reference/gtksource/style-scheme-manager.md) | Provides access to StyleSchemes. |
| [GtkSourceStyleSchemePreview](.gtkx/reference/gtksource/style-scheme-preview.md) | A preview widget for StyleScheme. |
| [GtkSourceTag](.gtkx/reference/gtksource/tag.md) | A tag that can be applied to text in a Buffer. |
| [GtkSourceView](.gtkx/reference/gtksource/view.md) | Subclass of Gtk.TextView. |
| [GtkSourceVimIMContext](.gtkx/reference/gtksource/vim-im-context.md) | Vim emulation. |
