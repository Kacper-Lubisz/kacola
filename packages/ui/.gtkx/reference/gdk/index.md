# Gdk elements

Elements in this namespace are imported from `@gtkx/jsx/gdk`; the matching classes, enums, and functions are imported from `@gtkx/gi/gdk`.

| Element | Description |
| --- | --- |
| [GdkAppLaunchContext](.gtkx/reference/gdk/app-launch-context.md) | Handles launching an application in a graphical context. |
| [GdkCairoContext](.gtkx/reference/gdk/cairo-context.md) | Represents the platform-specific draw context. |
| [GdkCicpParams](.gtkx/reference/gdk/cicp-params.md) | Contains the parameters that define a colorstate with cicp parameters. |
| [GdkClipboard](.gtkx/reference/gdk/clipboard.md) | Represents data shared between applications or inside an application. |
| [GdkContentDeserializer](.gtkx/reference/gdk/content-deserializer.md) | Deserializes content received via inter-application data transfers. |
| [GdkContentProvider](.gtkx/reference/gdk/content-provider.md) | Provides content for the clipboard or for drag-and-drop operations in a number of formats. |
| [GdkContentSerializer](.gtkx/reference/gdk/content-serializer.md) | Serializes content for inter-application data transfers. |
| [GdkCursor](.gtkx/reference/gdk/cursor.md) | Used to create and destroy cursors. |
| [GdkDevice](.gtkx/reference/gdk/device.md) | Represents an input device, such as a keyboard, mouse or touchpad. |
| [GdkDeviceTool](.gtkx/reference/gdk/device-tool.md) | A physical tool associated to a GdkDevice. |
| [GdkDisplay](.gtkx/reference/gdk/display.md) | A representation of a workstation. |
| [GdkDisplayManager](.gtkx/reference/gdk/display-manager.md) | Offers notification when displays appear or disappear. |
| [GdkDmabufTexture](.gtkx/reference/gdk/dmabuf-texture.md) | A GdkTexture representing a DMA buffer. |
| [GdkDmabufTextureBuilder](.gtkx/reference/gdk/dmabuf-texture-builder.md) | Constructs Gdk.Texture objects from DMA buffers. |
| [GdkDrag](.gtkx/reference/gdk/drag.md) | Represents the source of an ongoing DND operation. |
| [GdkDrawContext](.gtkx/reference/gdk/draw-context.md) | Base class for objects implementing different rendering methods. |
| [GdkDrop](.gtkx/reference/gdk/drop.md) | Represents the target of an ongoing DND operation. |
| [GdkFrameClock](.gtkx/reference/gdk/frame-clock.md) | Tells the application when to update and repaint a surface. |
| [GdkGLContext](.gtkx/reference/gdk/gl-context.md) | Represents a platform-specific OpenGL draw context. |
| [GdkGLTexture](.gtkx/reference/gdk/gl-texture.md) | A GdkTexture representing a GL texture object. |
| [GdkGLTextureBuilder](.gtkx/reference/gdk/gl-texture-builder.md) | Constructs Gdk.Texture objects from GL textures. |
| [GdkMemoryTexture](.gtkx/reference/gdk/memory-texture.md) | A GdkTexture representing image data in memory. |
| [GdkMemoryTextureBuilder](.gtkx/reference/gdk/memory-texture-builder.md) | Constructs Gdk.Texture objects from system memory provided via GLib.Bytes. |
| [GdkMonitor](.gtkx/reference/gdk/monitor.md) | Represents the individual outputs that are associated with a GdkDisplay. |
| [GdkSeat](.gtkx/reference/gdk/seat.md) | Represents a collection of input devices that belong to a user. |
| [GdkSnapshot](.gtkx/reference/gdk/snapshot.md) | Base type for snapshot operations. |
| [GdkSurface](.gtkx/reference/gdk/surface.md) | Represents a rectangular region on the screen. |
| [GdkTexture](.gtkx/reference/gdk/texture.md) | Refers to pixel data in various forms. |
| [GdkVulkanContext](.gtkx/reference/gdk/vulkan-context.md) | Represents the platform-specific Vulkan draw context. |
