# GdkPixbuf elements

Elements in this namespace are imported from `@gtkx/jsx/gdkpixbuf`; the matching classes, enums, and functions are imported from `@gtkx/gi/gdkpixbuf`.

| Element | Description |
| --- | --- |
| [GdkPixbuf](.gtkx/reference/gdkpixbuf/pixbuf.md) | A pixel buffer. |
| [GdkPixbufAnimation](.gtkx/reference/gdkpixbuf/pixbuf-animation.md) | An opaque object representing an animation. |
| [GdkPixbufAnimationIter](.gtkx/reference/gdkpixbuf/pixbuf-animation-iter.md) | An opaque object representing an iterator which points to a certain position in an animation. |
| [GdkPixbufLoader](.gtkx/reference/gdkpixbuf/pixbuf-loader.md) | Incremental image loader. |
| [GdkPixbufNonAnim](.gtkx/reference/gdkpixbuf/pixbuf-non-anim.md) |  |
| [GdkPixbufSimpleAnim](.gtkx/reference/gdkpixbuf/pixbuf-simple-anim.md) | An opaque struct representing a simple animation. |
| [GdkPixbufSimpleAnimIter](.gtkx/reference/gdkpixbuf/pixbuf-simple-anim-iter.md) |  |
