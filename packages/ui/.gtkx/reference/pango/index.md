# Pango elements

Elements in this namespace are imported from `@gtkx/jsx/pango`; the matching classes, enums, and functions are imported from `@gtkx/gi/pango`.

| Element | Description |
| --- | --- |
| [PangoContext](.gtkx/reference/pango/context.md) | A PangoContext stores global information used to control the itemization process. |
| [PangoCoverage](.gtkx/reference/pango/coverage.md) | A PangoCoverage structure is a map from Unicode characters to Pango.CoverageLevel values. |
| [PangoFont](.gtkx/reference/pango/font.md) | A PangoFont is used to represent a font in a rendering-system-independent manner. |
| [PangoFontFace](.gtkx/reference/pango/font-face.md) | A PangoFontFace is used to represent a group of fonts with the same family, slant, weight, and width, but varying sizes. |
| [PangoFontFamily](.gtkx/reference/pango/font-family.md) | A PangoFontFamily is used to represent a family of related font faces. |
| [PangoFontMap](.gtkx/reference/pango/font-map.md) | A PangoFontMap represents the set of fonts available for a particular rendering system. |
| [PangoFontset](.gtkx/reference/pango/fontset.md) | A PangoFontset represents a set of PangoFont to use when rendering text. |
| [PangoFontsetSimple](.gtkx/reference/pango/fontset-simple.md) | PangoFontsetSimple is a implementation of the abstract PangoFontset base class as an array of fonts. |
| [PangoLayout](.gtkx/reference/pango/layout.md) | A PangoLayout structure represents an entire paragraph of text. |
| [PangoRenderer](.gtkx/reference/pango/renderer.md) | PangoRenderer is a base class for objects that can render text provided as PangoGlyphString or PangoLayout. |
