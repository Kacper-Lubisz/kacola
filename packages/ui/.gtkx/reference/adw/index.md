# Adw elements

Elements in this namespace are imported from `@gtkx/jsx/adw`; the matching classes, enums, and functions are imported from `@gtkx/gi/adw`.

| [AdwAboutDialog](.gtkx/reference/adw/about-dialog.md) | A dialog showing information about the application. |

| [AdwActionRow](.gtkx/reference/adw/action-row.md) | A Gtk.ListBoxRow used to present actions. |

| [AdwBanner](.gtkx/reference/adw/banner.md) | A bar with contextual information. |
