# AdwNoneAnimationTarget

An `AnimationTarget` that doesn't do anything.

_Available since 1.9._

```tsx
import { AdwNoneAnimationTarget } from "@gtkx/jsx/adw";
```

## Hierarchy

[GObject](.gtkx/reference/gobject/object.md) → [AdwAnimationTarget](.gtkx/reference/adw/animation-target.md) → **AdwNoneAnimationTarget**

## Props

`ref` receives the `Adw.NoneAnimationTarget` instance. Every mutable property also has an `onNotify<Prop>` handler prop called with the new value when the property changes. Props inherited from ancestor elements are documented on their own pages.
